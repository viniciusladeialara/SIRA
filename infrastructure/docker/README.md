# SIRA - Infrastructure & Docker

As definições centrais de contêineres e orquestração do projeto estão consolidadas no arquivo [`docker-compose.yml`](../../docker-compose.yml) na raiz do repositório.

Este diretório armazena configurações auxiliares e dados específicos de serviços conteinerizados:
- `pgadmin/`: Arquivo de auto-carregamento de conexões (`servers.json`) para o pgAdmin 4.
