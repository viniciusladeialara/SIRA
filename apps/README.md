# SIRA - Apps

Este diretório contém as aplicações executáveis do ecossistema SIRA:

- `api/`: Backend API desenvolvido em **NestJS** (TypeScript).
- `web/`: Frontend Web desenvolvido em **Next.js** (App Router, TailwindCSS, Shadcn/UI).
- `optimizer/`: Motor de otimização de alocação de horários e recursos acadêmicos.
