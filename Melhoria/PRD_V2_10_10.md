# SIRA – Plano de Evolução para Nível 10/10

## Objetivo

Elevar a plataforma SIRA do estágio atual (arquitetura corporativa local) para um nível próximo de produção enterprise, preservando a simplicidade operacional, evitando complexidade prematura e mantendo compatibilidade com a arquitetura existente.

---

# EPIC 1 – Governança de Banco de Dados Profissional

## Objetivo
Substituir dependência de scripts SQL manuais por versionamento oficial e rastreável.

## Entregas

### E1.1 – Prisma Migrate como fonte da verdade

Implementar:

```bash
npx prisma migrate dev
npx prisma migrate deploy
```

Estrutura:

```text
database/
└── migrations/
```

### Critérios de aceite

- Todas as alterações estruturais passam por migration.
- Nenhuma alteração manual diretamente em produção.
- Ambiente novo pode ser reconstruído apenas pelas migrations.

---

## E1.2 – Controle de versão de Seeds

Criar tabela:

```sql
core.seed_history
```

Campos:

```sql
id
versao
executado_em
executado_por
```

### Critérios

- Cada carga registrada.
- Possibilidade de auditoria.

